# Wukong Benchmark Tool for VK

Автоматизированный инструмент для запуска Black Myth: Wukong Benchmark Tool на C#.

## Что делает

- Применяет настройки CPU-теста (1280×720, Low)
- Запускает бенчмарк, проходит меню, ждёт завершения
- Применяет настройки GPU-теста (1920×1080, Max)
- Запускает бенчмарк повторно
- Парсит JSON-результаты и выводит отчёт

## Требования

- Windows 10/11
- .NET 8.0
- Установленный Black Myth: Wukong Benchmark Tool (Steam)

## Запуск с указанием пути

```powershell

 .\WukongBenchmarkToolForVK.exe "D:\SteamLibrary\steamapps\common\Black Myth Wukong Benchmark Tool"
```
## Запуск без указания пути

```powershell

.\WukongBenchmarkToolForVK.exe


## Важные ограничения и предупреждения.

При прогоне программы не трогайте мышь и клавиатуру, пожалуйста.

Во время работы программа эмулирует ввод через WinAPI (`SendInput`), чтобы проходить меню и запускать тесты. **Любое вмешательство с вашей стороны ломает сценарий**:

- клик уйдёт в другое окно;
- фокус сместится с бенчмарка;
- тест не запустится, и программа зависнет.

- **Координаты кнопки «Тест быстродействия» захардкожены** (11.5% от левой границы, 44.4% от верхней)

## Сколько ждать

Полный цикл - два теста плюс паузы между ними. Занимает **около 10 минут**:

| Этап | Время |
|---|---|
| Загрузка + прогрузка UI | ~40 сек |
| CPU-тест | ~3 мин |
| Пауза + перезапуск | ~30 сек |
| Загрузка + прогрузка UI | ~40 сек |
| GPU-тест | ~3 мин |
| Парсинг и отчёт | ~10 сек |
| **Итого** | **~8–10 минут** |

Как раз успеет завариться кофе. Готовый отчёт появится в консоли и в файле `report_ГГГГ-ММ-ДД_ЧЧ-ММ-СС.txt` рядом с `.exe`.

## Как работает

### 1. Подготовка настроек
Программа меняет параметры бенчмарка в файле `GameUserSettings.ini`, который лежит в папке `b1\Saved\Config\Windows\`. Каждый тест использует свой набор:

- **CPU-тест:** разрешение 1280×720, Low, RTX выключен (чтобы нагрузка легла на процессор, а не на видеокарту).
- **GPU-тест:** разрешение 1920×1080, максимальное качество (чтобы загрузить видеокарту по полной).

Разные разрешения и качество специально разведены, чтобы по разнице FPS можно было понять, где узкое место системы.

### 2. Запуск и навигация
Программа запускает `b1-Win64-Shipping.exe` и ждёт появления окна. Дальше эмулирует ввод:

- клик мышью по центру окна (чтобы окно получило фокус);
- `Space` + `Enter` - прохождение приветственного экрана;
- клик по кнопке «Тест быстродействия» (координаты - в процентах от размеров окна, чтобы не зависеть от разрешения монитора);
- `Enter` - подтверждение запуска теста.

### 3. Ожидание и выход
Программа не отслеживает прогресс теста. Она просто ждёт ~3 минуты, а потом выходит из меню результатов:

- `Esc` открывает диалог выхода;
- `Enter` подтверждает возврат в главное меню.

Корректный выход через меню нужен, чтобы бенчмарк успевал сохранить JSON с результатами в `%TEMP%\b1\BenchMarkHistory\Tool\`.

### 4. Парсинг результата
Готовый JSON читается парсером `BenchmarkResultParser`, из него достаются все нужные метрики. Отчёт выводится в консоль и параллельно дублируется в файл через `TeeWriter`.
